# Win11Taskbar 1.1.1

Рабочая переносимая сборка для **Windows 10 22H2 x64**, C# / .NET 8 / WPF.

## Запуск

Откройте `Portable\Win11Taskbar.exe`. Среда .NET включена в папку Portable; копируйте папку целиком. UAC не требуется. При первом запуске предлагается включить автозапуск; без выбора этой опции запись Run не создаётся.

Крестик закрывает окно в трей. Полный выход: значок приложения → **Выход** либо Дополнительно → Восстановить, затем О программе → Выход. Восстановление работает и при выключении оформления переключателем.

Изменения в окне настроек и быстрый выбор стиля из трея попадают в черновик. Превью обновляется сразу. Нажмите **Сохранить**, чтобы записать настройки и применить их к рабочему столу, или **Отменить изменения**, чтобы вернуться к сохранённому состоянию.

## Реализовано

- Поиск Shell_TrayWnd / Shell_SecondaryTrayWnd, изменение расположения штатных элементов панели без замены Explorer.
- Центрирование кнопок «Пуск», поиска, представления задач и открытых приложений. Доступны три варианта выравнивания и четыре кривые анимации.
- В режимах центрирования программа пытается выровнять системные окна «Пуск» и поиска. Размер и содержимое окон определяет Windows. Если оболочка не предоставляет доступное окно, действует её обычное размещение.
- Пять вариантов фона, скругления, Floating и автоматический подбор оттенка под тему системной панели. Плавающий стиль смещает трей внутрь отступа, чтобы сохранить кнопку «Свернуть все окна».
- Новый интерфейс настроек с шестью страницами, тремя темами, карточками стилей и живым превью. Палитра цветов поддерживает готовые оттенки, ручной HEX и сравнение старого и нового цвета. В меню трея можно быстро выбрать стиль для черновика и открыть команды обслуживания.
- Видимость Start, Task View, существующей кнопки поиска, системного трея и часов. Содержимое трея и его меню остаются штатными.
- Применение к основной панели или ко всем обнаруженным панелям; сведения о дисплее и DPI.
- События WinEvent вне процесса Explorer, TaskbarCreated, WM_DISPLAYCHANGE, WM_SETTINGCHANGE и WM_DPICHANGED. Проверка координат каждые 2,5 секунды страхует пропущенные события и запрашивает пересчёт только при изменении. Таймер анимации работает только во время перемещения.
- Настройки и данные восстановления записываются в JSON с принудительным сбросом на диск перед заменой файла. Если файл повреждён, запуск продолжается. Повреждённый файл сохраняется рядом с расширением `.corrupt-…`, а для настроек загружаются значения по умолчанию. Журнал находится в `Logs\latest.log`.
- Автозапуск текущего пользователя HKCU Run, трей, onboarding, восстановление исходного региона/координат/видимости, отдельный процесс-сторож на случай аварии.
- Расширяемая проверка HTTPS GitHub Releases API. Загрузки и установки обновлений нет; `updateEndpoint` по умолчанию пуст, потому что публичный репозиторий не создан.

## Ограничения этой версии

Это безопасная реализация доступного подмножества большого ТЗ, а не полная замена панели Windows 11.

- Официального API для центрирования Start Windows 10 нет. Имена дочерних окон и расположение Explorer — внутренние детали оболочки; алгоритм проверен на установленной Windows 10 build 19045. На других сборках возможен безопасный отказ от центрирования.
- Acrylic использует необязательный **недокументированный** SetWindowCompositionAttribute. Он изолирован в Native и выключается переключателем в Advanced. При восстановлении возвращается системная композиция; исходный эффект стороннего кастомизатора прочитать нельзя. Другие программы изменения панели одновременно использовать не следует.
- Сила blur управляется Windows. Blur Strength, тень, обводка, высота и размер иконок меняют **только превью** и помечены в UI. Размеры нативных иконок/панели сохраняются: их надёжная замена потребовала бы вмешательства во внутреннюю компоновку Explorer. Mica не реализована.
- Floating не поднимает всю панель над краем экрана: горизонтальный отступ 0–16 DIP, вертикальный максимум 2 физических пикселя, чтобы не обрезать цели нажатий. Радиус 0–30 DIP. Режим Windows 11 — визуальный пресет, не настоящее меню Пуск Windows 11.
- Системная область уведомлений сохраняется. Новый дизайн применяется к меню самого Win11Taskbar. Отдельные профили мониторов, масштабирование нативных иконок, дополнительные языки и анимация появления фона отсутствуют в этой версии.
- Вертикальные панели не изменяются. Windows 11 запускает настройки/превью без изменения оболочки.
- Проверена одна подключённая панель, 1920×1080, DPI 96. Подключение второго физического дисплея, смена DPI/разрешения и реальный перезапуск Explorer в этой сессии не проверялись. Их обработчики реализованы, но это не заменяет проверку на оборудовании.
- Расчёт позиции окон «Пуск» и поиска проверен для нескольких вариантов рабочей области. Фактическое перемещение открытых нативных окон на этой машине пока не подтверждено.
- Сторож восстанавливает панель при завершении основного процесса. Одновременное принудительное завершение всего дерева процессов лишает приложение этой защиты; сохранённый журнал восстанавливается при следующем запуске.
- Исполняемые файлы локальной сборки не подписаны.
- Замер в трее на этой машине: 0 мс CPU за 5 секунд. При открытом окне в текущей среде инструментов UI Automation наблюдалась повышенная нагрузка; причину полностью локализовать не удалось. Поэтому это ещё не проверенная на длительном использовании production-версия.

## Архитектура и назначение файлов

```text
Win11Taskbar.sln
Directory.Build.props                    общие параметры .NET 8/x64
Win11Taskbar.App/
  App.xaml                              общие стили WPF и переключатели
  App.xaml.cs                           жизненный цикл, трей, сторож, single instance
  MainWindow.xaml                       каркас, title bar, навигация и превью
  MainWindow.xaml.cs                     страницы настроек, привязки и команды
  SmokeTests.cs                         интеграционные проверки на живом Explorer
  app.manifest                          asInvoker, PerMonitorV2
Win11Taskbar.Core/
  Settings.cs                           модель с INotifyPropertyChanged
  Services.cs                           JSON, логи, автозапуск, обновления
  TaskbarService.cs                     поиск, события, центрирование, анимации, restore
Win11Taskbar.Native/
  NativeMethods.cs                      Win32 P/Invoke и изолированный Acrylic
  WindowSnapshot.cs                     снимки регионов, координат и видимости
Installer/Win11Taskbar.iss               Inno Setup: per-user установка/удаление
build.ps1                               воспроизводимая сборка
Portable/                               готовые EXE/DLL и среда .NET
Verification/                           результаты тестов и отрисовки UI
```

Зависимости: App → Core → Native. Внешних NuGet-библиотек нет. WPF/Windows Forms (только NotifyIcon), UI Automation, Win32 входят в Windows Desktop runtime. Модель Settings служит источником привязок; маршрутизация страниц и команды пока находятся в code-behind. Полный MVVM с отдельными ViewModel — дальнейший рефакторинг.

Все исходные файлы содержат полный рабочий код. Полные пути получают добавлением указанной структуры к каталогу этого README; solution открывается в Visual Studio 2022 с .NET desktop workload.

## Сборка и installer

```powershell
dotnet build Win11Taskbar.sln -c Release
./build.ps1
# При установленном Inno Setup 6:
./build.ps1 -Installer
```

Inno Setup устанавливает в `%LocalAppData%\Programs\Win11Taskbar`, создаёт Start Menu shortcut, опционально Desktop shortcut и автозапуск. Перед удалением приложение нужно закрыть через трей (проверяется mutex). Удаление запускает `--restore`, убирает Run и предлагает удалить настройки.

Скрипт установщика подготовлен. **Setup EXE в этой сессии не собран:** компилятор Inno Setup отсутствовал, загрузка с официальных адресов завершалась HTTP 404/504 и таймаутами. Готовая Portable-сборка не требует установщика.

## Проверки

```powershell
./Portable/Win11Taskbar.exe --smoke-test 'C:\Temp\Win11TaskbarTests'
```

Перед тестированием закройте обычный экземпляр приложения. Тест временно меняет реальную панель и восстанавливает её, проверяет JSON и повреждённый конфиг, изменение нативных координат, видимость, восстановление региона, аварийное завершение отдельного экземпляра и работу его сторожа. Создаёт `smoke-results.txt`, диагностические JSON/TXT и PNG светлой/тёмной темы. Тест не перезапускает Explorer и не меняет автозапуск.

Фактические результаты текущего запуска находятся в `Verification\smoke-results.txt`. Компиляция Release: 0 ошибок, 0 предупреждений. Механизм компьютерного захвата окна возвращал `window capture timed out`; PNG получены собственным WPF RenderTargetBitmap и просмотрены вручную.
